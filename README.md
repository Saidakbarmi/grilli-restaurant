## 🌟 Overview

**Grilli** is a high-end restaurant web platform designed to deliver an immersive and authentic culinary atmosphere directly through the browser. Built from the ground up focusing on visual storytelling, fluid micro-interactions, and flawless responsiveness across all screen sizes (mobile, tablet, ultra-wide desktop).

---

## ✨ Key Features

- 🎥 **Cinematic Video Hero Intro** — Smooth video background transition with dynamic hero image carousel.
- 🎭 **GSAP & ScrollTrigger Animations** — Masked reveal effects, magnetic hover interactions, and smooth viewport triggers.
- 📖 **Interactive Digital Menu** — Categorized dining selections with modals, dietary indicators, and pricing highlights.
- 📅 **Smart Table Reservation System** — Interactive booking modal with date/time pickers and automated validation status feedback.
- 📱 **Adaptive Responsive Design** — Pixel-perfect layout tailored for mobile devices, tablets, and high-resolution displays.
- 🎨 **Glassmorphism & Luxury Aesthetics** — Custom CSS filters, SVG separators, and carefully curated typography.

---

## 🛠️ Tech Stack

- **Markup:** Semantic HTML5, SVG Icons
- **Styling:** Custom Vanilla CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism)
- **Scripting:** Modern JavaScript (ES6+ Modules, DOM Manipulation)
- **Animation Engine:** GreenSock GSAP 3.13, ScrollTrigger
- **Iconography:** Ionicons 5.5

---

## 🚀 Getting Started

Simply clone the repository and launch `index.html` in your browser or with Live Server:

```bash
git clone https://github.com/Saidakbarmi/grilli-restaurant.git
cd grilli-restaurant
```

Open `index.html` in any modern web browser.
